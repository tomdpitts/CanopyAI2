# Lockfile for .venv_df — the isolated DeepForest environment (CPython 3.10).
#
# WHAT IT IS FOR: running `deepforest.evaluate_boxes`, the NeonTreeEvaluation authors'
# own scorer, via df_scorer.py. Every reported NEON number comes from it (commit
# 7a51251 removed the re-written scorer so only the benchmark's provided evaluation
# code is used). It scores saved prediction JSONs on CPU — it never loads a model, a
# GPU, or DINOv3.
#
# WHY IT STAYS SEPARATE FROM .venv: to keep DeepForest's ~50-package surface
# (pytorch-lightning, kornia, timm, geopandas, rasterio, supervision) from dragging the
# main environment on any future upgrade. Note that at these pinned versions the two
# envs do NOT actually conflict — DeepForest's constraints are loose ranges
# (torch>=2.2.0, numpy unpinned, transformers!=4.57,!=5.1.0) and both had resolved to
# identical torch/torchvision/transformers/numpy/scipy/pillow/matplotlib. The isolation
# is deliberate insurance, not a live clash.
#
# PROVENANCE: exact freeze read from the surviving .venv_df dist-info on 2026-08-17,
# after the machine migration left site-packages intact but the interpreter symlinks
# missing. These are the versions that produced the 5-seed NEON F1 0.728 +- 0.003 band.
#
# REBUILD (from boxinst_commonality_tcd_04/modal_neon_multiseed/):
#   ~/.pyenv/versions/3.10.20/bin/python -m venv .venv_df
#   .venv_df/bin/pip install -r requirements-deepforest.txt
