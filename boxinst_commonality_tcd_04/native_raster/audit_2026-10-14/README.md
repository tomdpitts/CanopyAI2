## A. Defects that hinder a baseline (need GPU; Modal workspace is paused)
1. **Box2Mask LR never annealed** (both backbones). The released schedule decays ×0.1 at 88.9% and 96.3% of the run (R-50 config: steps 26,768 / 28,999 of 30,114). Our val early stop ended R-50 at iter 20,076 and Swin-L at ~32,400, and every logged LR is 1e-5. Verified independently from `box2mask_evidence/config_r50_dumped.py` and the R-50 log. Fix: resume both from their last checkpoints to the end of the schedule, early stopping off (~2 A100-h each). Effect unmeasured.
2. **Box2Mask Swin-L was stopped by a 5 h wall clock**, not by the patience rule (patience 2/4). The resumed run was then killed by hand at epoch 4.84. paper.tex note d's "three later evaluations below the peak" is false: the third value is a re-evaluation of the same weights on resume.
3. **SelvaBox → SAM 3: ranking key.** The released mask stage (`preset_seg_multi_NQOS_selvamask_SAM3_FT_fast.yaml`, aggregator 2; verified) ranks by sqrt(det × SAM iou); we rank by detector score alone. CPU re-score, maxDets 600: on the pre-fix file 0.5710 → 0.5993 AP50, 0.2111 → 0.2454 AP50:95; on the seam-fixed file 0.5984 → **0.6141** AP50, 0.2207 → 0.2502 AP50:95, box 0.7618 (0.6198 at maxDets 1,600; `../seamfix/selvabox_gmean_rescore.py`, provisional: 9% of SAM scores are local). Ordering unchanged (DT2 0.630, LACE 0.647). Its ioa-disambiguate mask NMS (0.05) and 0.6 threshold are not applied either (CONFIG_AUDIT §5 still open). Paper is silent on this.
4. **SelvaBox → SAM 3: field of view.** We prompt SAM 3 on the whole 2048 tile resized to 1777, i.e. 20.3 cm/px at the 1008 px encoder. CanopyRS prompts each box on its source subtile (`segmenter.py:137-147`), 10.2 cm/px on 1024 benchmark subtiles. The median GT crown gets 5.9 vs 11.8 mask-logit cells. Fix = per-subtile SAM re-run from `raw_dets` (GPU; with the interior edge band every kept box is ≥ 51.2 px inside its subtile, so masks are not truncated). tab:gtbox's FT arm (`gtbox_modal.py:45,324`) has the same path. Paper wording at L779 / L945 / L1189 / note c overstates fidelity; "0.045 m/px" is the quality preset (fast is 0.07).
5. **Detectree2 `INPUT.MIN_SIZE_TEST` 1000 vs released 800** was never checked on val. Our docs say detectree2's own tiles are smaller than 800, which is wrong: they are ~1000 px. Cheap val check (~$0.5): if 800 wins, this becomes a defect.

- SelvaBox mask post-processing (released: downscale to 512, holes filled, parts < 50 px² dropped) not applied; net effect unknown.
